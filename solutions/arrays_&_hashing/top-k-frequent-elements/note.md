## Sorting

```
-> Get number frequency
-> sort
-> extract top k
```

## Heap

use heap(priority_queue) instead of vector

sort can be done automatically and we dont need to keep a `n` size vector


## Bucket Sort

key point: the maximum possible frequency is the length of the array

we can represent frequency by the index of an array: `freq[3] = {5, 7}` means number 5 and 7 appears 3 times
